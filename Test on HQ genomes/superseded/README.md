# Superseded

These are the first two versions of the GEM high quality genome predictions, kept for the record. Do not use them.

The first version gave the model phylogeny and 16S inputs in a different numerical form from its training data, so the
predicted doubling times were squeezed toward fast growth (median 0.6 hours against 7 hours for the training species,
none above 24 hours). The second version fixed that but did not use codon usage bias and gave only the doubling time
rescaled to 20 C. The current predictions and report are one folder up.
